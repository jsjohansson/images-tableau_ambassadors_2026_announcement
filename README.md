# 2026 Tableau Ambassador Images 🤘

Ready-to-post announcement graphics for **every** 2026–2027 Tableau Ambassador.

I made one of these for my own LinkedIn post about becoming a Tableau Ambassador — then figured, why stop at me? So I built the rest of them.

Grab yours, post it, tag the DataFam. 🚀

---

## Get your image

1. Press **`t`** on this page (or use the search box) and type your name
2. Open your `.png` and click **Download**
3. Post it on LinkedIn, X, Slack, your blog — wherever you like

Files are named exactly as you appear on the [Tableau Ambassadors page](https://www.tableau.com/community/community-leaders/ambassadors), so `John Johansson.png`, and so on.

## What you get

| | |
|---|---|
| **Format** | PNG |
| **Size** | 1920 × 1920 (square) |
| **Built for** | LinkedIn, X, Instagram, Slack, anywhere square works |

Your headshot in the circle, your name underneath, official Tableau Ambassador lockup — same layout for everyone.

## How it was made

A simple web scrape pulled the names and headshots straight from the public Tableau Ambassadors page. From there I set my AI sandbox loose to build a template and batch-generate the full set.

Photos and names come from the Ambassadors page itself, so whatever Tableau has on file is what you'll see here.

## Something off?

Wrong photo, misspelled name, awkward crop, or you'd just rather use a different picture — **DM me your name and the image you want** and I'll send you a fixed one directly. 🍻
